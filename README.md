# DM Status tracker
Simple tracker for dungeon and dragon game designed for DM to use.
The tracker contains tracker for blood, ammunition, and status effects with 15 available trackers.

**This was built with a specific system of health in mind, so it might not cater to general campaigns.**

## Features
- Renameable trackers
- Blood tracker
- Ammunition tracker
- Status effects tracker
- Apply turn (apply rates and effects which decreases the duration)
- Change logs (Logs every changes that happens in the tracker)
